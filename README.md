# Cosc471-Audio-Visualizer
PROJECT REPORT

The goal is to process audio data and map it effectively to graphical transformations in a 3D environment. Our project applies several fundamental computer graphics concepts learned in class. We used geometric modeling to create 3D objects such as cubes and bars. These objects are placed within a 3D scene using transformations such as translation, scaling, and rotation. Transformations play a key role in the visualization. Scaling is used to dynamically change the height of the frequency bars and the size of the cube based on audio input. Rotation is used on the cube to create continuous motion, while translation is used to position objects within the scene.

The visualizer includes a 3D cube and multiple frequency bars. The cube reacts to overall audio intensity, while the bars represent different frequency ranges of the audio signal. A particle background was added to enhance the visual experience. We implemented the Web Audio API to process the sound input. The AudioContext which was created to manage audio operations, also an AnalyserNode used to extract frequency data from the audio signal. The method getByteFrequencyData() is used to retrieve real-time frequency values. Three.js is used to create and render the 3D scene from a 2D screen. A perspective camera and WebGL renderer are configured to display the scene. The average amplitude of the audio signal is calculated and used to scale the cube dynamically. Each frequency bar corresponds to a specific frequency bin, and its height is adjusted based on the corresponding audio value. Which creates a real-time visual representation of the sound spectrum. The cube was repositioned to avoid overlap with the frequency bars, and camera movement was introduced to create a more dynamic perspective. The scene is continuously updated using an animation loop, allowing the visual elements to respond dynamically to incoming audio data.
